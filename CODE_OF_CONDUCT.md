# Code of Conduct

We are committed to a welcoming, harassment-free community.

Be respectful, assume good intent, give actionable technical feedback, and focus discussion on the project. Harassment, discrimination, threats, doxxing, and publication of another person's private information are not tolerated.

Project maintainers may edit or remove inappropriate content and may temporarily or permanently restrict participation when necessary. Report conduct concerns privately through the repository owner's GitHub profile rather than in a public issue.
